Dino Runner

Jump the cacti, duck the birds, and see how far you get. The game speeds up as you go.

How to play

Jump
Space, Up arrow or W; or tap the game. Tap briefly for a small hop.
Duck
Down arrow or S (hold). In the air, it makes you land faster.
Pause
P or Esc. The game also pauses when you switch tabs.

Written in plain JavaScript using classes (no libraries). Source code on GitHub · My portfolio
